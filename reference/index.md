# Package index

## Generate sequence cohorts

Functions for generating sequence cohorts for sequence symmetry
analysis.

- [`generateSequenceCohortSet()`](https://ohdsi.github.io/CohortSymmetry/reference/generateSequenceCohortSet.md)
  : Intersecting the index and marker cohorts prior to calculating
  Sequence Symmetry Ratios

## Sequence symmetry analysis

Functions for summarising, visualising, and tabulating sequence ratios.

- [`summariseSequenceRatios()`](https://ohdsi.github.io/CohortSymmetry/reference/summariseSequenceRatios.md)
  : Sequence ratio calculations
- [`plotSequenceRatios()`](https://ohdsi.github.io/CohortSymmetry/reference/plotSequenceRatios.md)
  : A plot for the sequence ratios.
- [`tableSequenceRatios()`](https://ohdsi.github.io/CohortSymmetry/reference/tableSequenceRatios.md)
  : A formatted visualization of sequence_symmetry objects.

## Temporal symmetry analysis

Functions for summarising, visualising, and tabulating temporal
symmetry.

- [`summariseTemporalSymmetry()`](https://ohdsi.github.io/CohortSymmetry/reference/summariseTemporalSymmetry.md)
  : Summarise temporal symmetry
- [`plotTemporalSymmetry()`](https://ohdsi.github.io/CohortSymmetry/reference/plotTemporalSymmetry.md)
  : A plot for the temporal symmetry of cohorts.
- [`tableTemporalSymmetry()`](https://ohdsi.github.io/CohortSymmetry/reference/tableTemporalSymmetry.md)
  : A formatted visualization of temporal_symmetry objects.

## Mock data
